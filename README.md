🖥️ Personal Portfolio Website

A modern, responsive, and fully interactive portfolio website built using the latest web technologies. Designed to showcase projects, skills, and professional experience with clean design, smooth animations, and fast performance.

🔗 Live Preview: https://p-o-r-t-f-o-l-i-o-link.netlify.app/

🧠 Tech Stack
⚙️ Technology       🔍 Description
⚛️ React            Component-based UI library
⚡ Vite             Lightning-fast development environment
🎨 Tailwind CSS     Utility-first CSS framework for styling
🧩 Framer Motion    Smooth animations and interactions
💬 TypeScript       Typed superset of JavaScript for better code quality

🛠️ Ideal For
👨‍💻 Developers & Designers showcasing skills  
📝 Personal branding and resumes  
📂 Projects and case studies  
🛍️ Freelancers & agencies portfolio display  

🚀 Getting Started
```bash
# 📦 Clone the repo
git clone https://github.com/Saurabh-1435/Personal-Portfolio.git

# 📂 Navigate to the project directory
cd Personal-Portfolio

# 🔧 Install dependencies
npm install

# ▶️ Start the development server
npm run dev
✨ Key Features
🖥️ Responsive Design – Perfectly optimized for desktop, tablet, and mobile devices

🎨 Animated Components – Smooth UI animations using Framer Motion

💡 Dark/Light Mode – Stylish theme toggle for user preference

📂 Projects Showcase – Interactive portfolio section with screenshots and details

📄 Resume Download – Easily accessible resume for recruiters

💬 Contact Form – Frontend-ready form section

⚡ Fast Performance – Powered by Vite for lightning-fast load times

🧼 Clean Codebase – Easy to maintain, scale, and extend
